Stage 1 · Initial access

Suspicious: IT Service Desk (mailbox storage) and DelivR Parcels. The other five are genuine.

Email that gave away the password: IT Service Desk.

Clues: lookalike domain; link goes somewhere other than the address shown; two-hour deadline; "Dear user". Not clues: spelling mistakes, logo, attachment, time sent.

Stage 5 · How it was possible

Flawed lines: 7, 11 and 18.

Fixes: line 7, salted hash with verify_hash; line 11, limit prompts and use number matching; line 18, check the role stored on the server.

Stage 7 · Close the door

  1. Deny 203.0.113.77, any port
  2. Deny 198.51.100.23, any port

  4. Allow 81.2.69.0/24, port 22

Stage 8 · Catch it next time

Train, then set the threshold to roughly 13–27% (all 8 attacks caught, at most 2 false alarms).

Answers: the attack with only 3 failed steps; at 1%, every attack is caught but analysts are flooded with false alarms.
